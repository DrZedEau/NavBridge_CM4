# 3D Printed Parts

STL files for the NavBridge CM4. *Not added yet.*

| Part | Description |
|---|---|
| Case | Base and top for the 100 × 100 mm board |
| Connector | Housing for the BMW navigation connector |

Board dimensions for the case: 100 × 100 × 1.6 mm, with 4 × M2.5 mounting holes at the corners, 3 mm from each edge. The KiCad project in [hardware/](../hardware/) can export a STEP model of the assembled board.

The previous board's case and connector are in the `3D/` folder of the [CM5 NavBridge](https://github.com/DrZedEau/CM5_NavBridge) repository.
